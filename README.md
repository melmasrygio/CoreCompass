# CoreCompass

CoreCompass optimizes data-driven workflows with high-performance processing, low-latency analytics, auto-scaling capabilities, delivering a robust engine for data-visualization applications.

CoreCompass is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/CoreCompass.git`
2. `cd CoreCompass`
3. Install in editable mode: `pip install -e .`

## Configuration

CoreCompass is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
